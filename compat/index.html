What the statuses mean

Runs: it passed the scripted in-game check (button presses, frames compared with reference images), or a 3D scene was seen. Starts: it draws, but no 3D scene was seen yet. Broken: it crashes, hangs or draws wrong; the game's details say what we know. Not checked yet: the run hasn't reached it. None of these means played start to finish.

About the speeds

Uncapped frames per second in each game's first 150 seconds with no buttons pressed, on the device named. Over 60 (50 for European copies) is full speed there. Gameplay can be heavier than intros.

Test devices

Adreno 8xx: Odin 3 Portal. Adreno 7xx: Odin 2 Portal, Retroid Pocket Duo. Mali: Retroid Pocket Flip. Each game was run on one of them, the 82 games of the in-game check on all four. No game files are hosted here.
